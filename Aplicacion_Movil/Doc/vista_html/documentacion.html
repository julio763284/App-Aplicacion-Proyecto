Descripción del Proyecto

Esta aplicación móvil está diseñada para facilitar la gestión y visualización de información de manera rápida e intuitiva, ofreciendo una interfaz moderna, dinámica y fácil de usar para todo ipo de usuarios. Además, permite optimizar procesos, mejorar la organización de datos y acceder a la información de forma segura y eficiente desde cualquier dispositivo móvil.

Arquitectura del Sistema

La aplicación está construida bajo una arquitectura moderna y escalable. El frontend se desarrolla en Flutter y el backend maneja la lógica del negocio.
